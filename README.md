
# 3-to-8 Decoder Using Verilog HDL

## Description
This project implements a 3-to-8 Decoder using Verilog Hardware Description Language (HDL). A 3-bit binary input is converted into one of eight active output lines based on the enable signal.

## Features
- 3-bit input and 8-bit output.
- Enable signal control.
- Implemented using Behavioral Modeling.
- Simulated using EDA Playground.
- Verified all 8 input combinations.

## Tools Used
- Verilog HDL
- EDA Playground
- Icarus Verilog (simulation, if used)

## Learning Outcomes
- Understanding decoder operation.
- Learning combinational circuit design.
- Practicing Verilog coding.
- Understanding testbench-based simulation.
